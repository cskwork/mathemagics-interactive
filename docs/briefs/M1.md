## 1. 목표

덧셈·뺄셈에 대해 "문제 JSON → 스텝 파생 → 그리드 렌더 → 애니메이션 재생 / 학생 입력" 전체 파이프라인을 완성한다. 이것이 앱 전체의 심장 — 이후 모든 마일스톤이 이 위에 쌓인다. UI 미감보다 **정확성·접근성·인터랙션 반응성** 우선 (비주얼 폴리시는 M2+).

## 2. 산출물

1. **시맨틱 문제 스키마** `src/lib/engine/types.ts` — PLAN §5.2 후보 A(`{id?, op, operands, method: "ltr"|"rtl", level, hints?}`) + 파생 스텝 타입(후보 B: `highlight|write|carry|strike|reveal`, `expect`, `narration` — narration은 로케일 키 객체).
2. **스텝 파생 엔진** `src/lib/engine/derive.ts` — 순수 함수 `deriveSteps(problem): Step[]`.
   - `add`/`sub` × `rtl`(학교식: 올림/빌림 표기 포함) × `ltr`(벤저민식: 앞자리부터 확정 + 뒤 자릿수로 인한 수정 처리 — book-content-map 1장 규칙 그대로).
   - 보수(complement) 뺄셈 변형은 스텝 narration 분기로 지원 (1장 §보수 참조).
   - 그리드 레이아웃 파생 `deriveGrid(problem): Grid` 도 순수 함수로 분리.
3. **세로셈 그리드 렌더러** `src/lib/components/ColumnGrid.svelte` — CSS Grid, 자릿수 1개=셀 1개, `font-variant-numeric: tabular-nums`, carry 행(위첨자 크기), 답 행, 밑줄. 셀 상태: idle/highlight/filled/correct/wrong.
4. **스텝 재생기** `src/lib/components/StepPlayer.svelte` — Step[]을 순서대로 연출: 재생/일시정지/이전/다음/처음부터, 속도 조절(1x/0.5x), `narration` 말풍선 + `aria-live` 낭독, `prefers-reduced-motion` 시 즉시 전환. CSS transition 기본, 시퀀싱 필요 시에만 Motion mini(~5KB) 추가 가능(사유 기록).
5. **digit-cell 에디터 + 가상 넘패드** `src/lib/components/DigitInput.svelte`, `NumPad.svelte` — 활성 셀 강조, method에 따른 auto-advance 방향(ltr/rtl), 셀 단위 즉시 정오 피드백(초록/빨강+흔들림), 넘패드 버튼 ≥48px, 물리 키보드(숫자·화살표·백스페이스) 병행, 모든 탭 즉각 시각 반응.
6. **데모 라우트** `#/dev/playground` — 문제 파라미터(자릿수, 올림 여부, op, method) 조절 → ① 애니메이션 재생 모드 ② 직접 입력 모드 전환 가능. (개발용 — 내비게이션에는 숨김 링크)
7. **문제 생성기(기초)** `src/lib/engine/generate.ts` — add/sub용: 자릿수·올림/빌림 포함 여부 파라미터로 문제 생성 (M2 레슨에서 사용). 시드 기반 결정적 생성(테스트 가능).

## 3. 완료 기준

- `deriveSteps`/`deriveGrid`/`generate` 단위 테스트: add/sub × ltr/rtl × 2~4자리 × 올림/빌림 유무 전 조합 + 경계(0 포함, 자릿수 증가 케이스: 999+1). 최종 답은 독립 계산(`a+b`)과 대조.
- 접근성: 셀 `aria-label`("십의 자리, 7"), DOM 순서=풀이 순서, 넘패드 버튼 라벨 — 테스트 또는 수동 확인 기록.
- `npm run check` · `npm test` · `npm run build` 통과 — 출력 원문을 M1-RESULT에.
- preview 수동 확인: playground에서 ltr 덧셈 1문제 애니메이션 재생 + rtl 뺄셈 1문제 직접 입력 완주 — 결과 기록.
