2. `PLAN.md` — §3.2(스킬트리), §7.1(X-다이어그램·치환 체인·누계 롤링 연출)

## 1. 목표

암산 메인 트랙의 몸통: 곱셈(2장 기초 → 3장 중급), 나눗셈(4장), 어림셈(5장)을 엔진·컴포넌트·레슨·SRS까지 관통시키고, 스킬트리 화면으로 학습 경로를 시각화한다.

## 2. 산출물

1. **엔진 확장** `src/lib/engine/` — 전부 순수 함수 + `deriveSteps` 일관 인터페이스:
   - 2장: 2×1·3×1 곱셈(반올림 보정 포함), 2자리 제곱(±d 기법)
   - 3장: 2×2 곱셈 4가지 방법(덧셈법·뺄셈법·인수분해법·11법 — 방법 선택이 학습 내용의 일부), 3자리 제곱
   - 4장: 1자리 나눗셈(좌→우, 나머지), 단순화(양쪽 2배 등)·소수화·배수판정(2~11)
   - 5장: 어림셈(자릿수 어림, 반올림 밴드) — 정답이 범위인 문제 유형 지원
2. **X-다이어그램 컴포넌트** — 제곱의 ±d 분기 도식. **재귀 중첩 지원**(3자리 제곱 내부에 2자리 제곱 다이어그램이 축소되어 들어감 — 확대/축소 전환 연출). book-content-map의 도식 구조 준수.
3. **치환 체인 컴포넌트** — `759+496 → +500 → −4` 화살표 애니메이션 (곱셈 반올림 보정에도 재사용).
4. **누계 롤링 카운터** — 부분곱 + running total, 숫자 롤링 전환.
5. **나눗셈 브래킷** — SVG 레이아웃(왼쪽 괄호형), 몫이 왼쪽부터 확정되는 digit-reveal.
6. **레슨 콘텐츠** — 2~5장 기법별 레슨(§3.2 스킬트리 순서, 내레이션·힌트 ko/en 자체 작성), 생성기 확장(기법별 파라미터), SRS 카드 자동 편입.
7. **스킬트리 화면** — `#/lessons`를 트리 뷰로 확장: 잠금/해금(PLAN §3.2 의존성), 마술 해금 슬롯 표시(내용물은 M5).

## 3. 완료 기준

- 엔진 테스트: 각 연산 × 방법 × 자릿수 조합, 결과를 독립 계산과 대조. 2×2 4가지 방법이 같은 답에 도달하는 속성 테스트.
- X-다이어그램 재귀 렌더(2자리→3자리 제곱) 확인 기록. preview에서 2장·3장·4장·5장 각 1레슨 완주 기록.
- `npm run check` · `npm test` · `npm run build` 통과 — 출력 원문 첨부.
