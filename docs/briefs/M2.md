## 1. 목표

M1의 계산 코어 위에 "레슨"이라는 학습 단위를 완성하고, 제1장 3개 레슨을 실제 플레이 가능하게 만든다. 여기서부터 아이가 보는 화면 — **비주얼 폴리시와 톤(8–13세, 유치함 배제)이 채점 기준에 들어간다.**

## 2. 산출물

1. **레슨 콘텐츠 스키마 + 로더** — `content/lessons/*.json`, 타입 `src/lib/lesson/types.ts`. 텍스트 필드는 전부 `{ko, en}` 로케일 키(ko 폴백). 로드 시 스키마 검증(직접 타입가드 우선, zod 도입 시 사유 기록).
2. **레슨 플레이어** `src/lib/lesson/LessonPlayer.svelte` — 5단계 상태 머신:
   ① 훅(해당 기법 마술 데모 3~10초 자동 시연, 건너뛰기 가능) → ② 예제 관찰(StepPlayer 재생 2~3문제) → ③ 페이딩(마지막 스텝부터 학생이 채움, `expect` 셀 점진 확대) → ④ 독립 연습(전체 입력) → ⑤ 완료(진도 저장 + 축하).
   상태 전이는 순수 함수로 분리해 단위 테스트.
3. **3단 힌트 사다리** — Point(해당 셀 하이라이트) → Teach(규칙 1줄 재설명 + 부분 시연) → Bottom-out(답 공개). 힌트 사용 이력을 progress에 기록, bottom-out 연속 남용 감지 시 ②단계로 부드럽게 복귀 권유.
4. **전략 카드** — 독립 연습 정답 후 "나는 이렇게 풀었어" 카드 선택(해당 기법/다른 기법/그냥 알았어), 기록만 (분석은 M3).
5. **제1장 콘텐츠 3레슨** — 좌→우 덧셈, 좌→우 뺄셈, 보수(complement). 문제는 M1 생성기 파라미터로 정의(하드코딩 최소화), 내레이션·힌트 텍스트 ko/en 작성. **원문 문장 복제 금지 — 규칙만 가져오고 문장은 자체 작성** (PLAN §10-1).
6. **레슨 목록 화면** `#/lessons` — 1장 3레슨 + 잠금 상태(선행: 덧셈→뺄셈→보수), 완료 표시. (스킬트리 비주얼은 M4에서 확장.)
7. **진도 저장** — StorageAdapter.progress에 레슨 상태(단계 도달, 정확도, 힌트 사용) 기록. 프로필별.

## 3. 완료 기준

- 상태 머신·힌트 사다리·잠금 로직 단위 테스트.
- preview 수동 확인: 새 프로필로 3레슨 연속 완주(훅부터 완료까지), 새로고침 후 진도 유지, ko/en 양쪽에서 레슨 1개 완주 — 결과 기록.
- 접근성: 단계 전환 `aria-live` 안내, 힌트 버튼 라벨, `prefers-reduced-motion` 준수.
- `npm run check` · `npm test` · `npm run build` 통과 — 출력 원문 첨부.
