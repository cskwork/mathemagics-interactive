## 구현 재개 절차

1. 순서 엄수: M1 → M2 → … → M6 (각 브리프의 "선행" 명시).
2. 착수 전 직전 마일스톤의 `M*-RESULT.md`를 읽고, 브리프의 가정(라이브러리 버전 등)을 착수 시점 기준으로 재확인.
3. 구현자는 로컬 커밋만, push는 오케스트레이터가 재검증(`npm run check`·`test`·`build`) 후 수행.
4. 완료 시 이 색인의 상태 갱신.
