## 1. 목표

최상급 콘텐츠(기억술 + 8장)와 셀프호스트 모드를 완성해 PLAN의 전체 범위를 닫는다.

## 2. 산출물

1. **기억술 — 로케일별 별도 모듈** (번역이 아님, PLAN §10-2):
   - `ko`: **한글 자음 매핑 신설계** — 0~9→한글 자음 매핑표(설계 근거·혼동 최소화 논리를 `docs/memory-system-ko.md`로 문서화), 아동 어휘 단어 후보 사전(`content/memory/ko-words.json`), 숫자↔단어 양방향 연습 레슨
   - `en`: 원서 Major System(1=t/d…0=s/z) 모듈 + 영어 단어 사전
   - 공통 엔진: 숫자열→단어 후보 탐색, 단어→숫자 검증(순수 함수)
2. **메모리 슬롯 UI** — 계산 중 중간값을 "단어 카드"로 저장하는 연출(손가락 저장은 손 아이콘 변형) — 8장 레슨에서 사용.
3. **8장 고급 곱셈** — 엔진+레슨: 4자리 제곱 → 3×2(분해·반올림·인수분해 선택) → 5자리 제곱(교차 결합) → 3×3(크로스 방법) → 5×5. X-다이어그램 재귀(M4) + 메모리 슬롯 결합. **자리올림 선예측은 하위 합이 1,000,000에 도달하는지 판단하며 5장 어림 스킬을 선행 요구** — 스킬트리 반영.
4. **셀프호스트 서버** `server/`:
   - Bun 단일 파일 서버(Hono + `bun:sqlite`) — 정적 빌드 서빙 + REST(profiles/progress/srsCards/settings CRUD, export/import)
   - **`/api/health`는 JSON `{app:"mathemagics", version}` 반환** (M0에서 확정한 probe 계약 — PLAN §6.1)
   - `RestAdapter` 본 구현(M0 stub 대체), SQLite 스키마 + 마이그레이션(ExportBundle schemaVersion과 정합)
   - `Dockerfile` + `docs/self-host.md`(bun 직접 실행·Docker·NAS 안내)
5. **ExportBundle UI** — 설정 화면에서 내보내기(JSON 다운로드)/가져오기(merge/replace 선택, 미리보기 후 적용).

## 3. 완료 기준

- 기억술 엔진 단위 테스트(ko/en 양방향 변환), 8장 엔진 독립 계산 대조 테스트.
- **왕복 이식 테스트**: 정적 모드 데이터 → export → 서버 모드 import → 재export 동등성(자동 테스트).
- 셀프호스트 확인: `bun run server` + Docker 빌드·기동, 브라우저에서 RestAdapter 자동 감지 → 프로필 CRUD 동작 — 기록.
- `npm run check` · `npm test` · `npm run build` 통과 — 출력 원문 첨부.
