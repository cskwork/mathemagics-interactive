# Domain Glossary

## Lesson technique

A named mental-math procedure whose rule, generated problem domain, worked transformations, expected learner input, and feedback all describe the same procedure.

## Exact answer

The value determined by the original arithmetic expression. An exact answer must not be used to construct information presented as an estimate of that answer.

## Estimate

A deliberately simplified approximate value computed only from the original operands and a stated rounding procedure.

## Estimation band

A lower and upper bound derived from directed rounding of the original operands. The exact answer is guaranteed to lie inside the band without being calculated first.

## Technique domain

The operand conditions under which a technique is both valid and pedagogically useful. Generated exercises for a named technique must satisfy its technique domain.

## Mod-sum check

A one-sided arithmetic check: a residue mismatch proves an answer is wrong, while a match does not prove the answer is correct.

## Mathematical magic trick

A deterministic procedure with explicit preconditions. An "always" claim applies only when every precondition and representation rule, including leading zeroes, is followed.

## Phonetic code

A mapping from pronounced consonant sounds to digits. Silent letters, spelling alone, and consonants separated into distinct sounds do not change the mapping.
